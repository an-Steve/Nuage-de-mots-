→  Fonctionnalités
   Fonctionnalités Principales

Génération automatique : Crée un nuage de mots à partir de n'importe quel texte
Filtrage intelligent : Supprime automatiquement les mots vides (articles, prépositions, etc.) en français et anglais
Personnalisation avancée : Nombreuses options de personnalisation disponibles

→  Options de Personnalisation
Palettes de Couleurs (6 thèmes)

🔥 Warm - Tons chauds orangés
🌊 Cool - Bleus et violets
🌿 Nature - Verts naturels
🌅 Sunset - Rose et orange
🌌 Ocean - Bleus profonds
🍇 Berry - Violets et roses

→ Formes de Nuage (4 options)

⭕ Cercle - Forme circulaire classique
❤️ Cœur - Parfait pour les messages d'amour
⭐ Étoile - Forme étoilée dynamique
☁️ Nuage - Forme organique

→ Options d'Animation

🔄 Rotation des mots - Rotation aléatoire pour un effet dynamique
✨ Animation au survol - Effets interactifs sur les mots
